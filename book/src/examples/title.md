# Examples

The [workspace example guide](../../../examples/README.md) owns setup and launch
commands. Choose a focused example, then inspect its protocol and client/server
sources from this checkout. Start with [simple_box](../../../examples/simple_box/README.md)
for movement/prediction/interpolation, [prespawn regressions](../../../crates/tests/src/client_server/prediction/prespawn.rs)
for matching local candidates, or [network_visibility](../../../examples/network_visibility/README.md)
for room-based delivery. An old screenshot or upstream hosted demo may use a
different rendering/API version; it is not qualification of this fork.
